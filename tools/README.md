# tools/ — 素材去背切圖腳本

這兩支 Python 腳本是用來把「多角龍研究員」的素材總表圖，自動裁切成一張一張透明背景 PNG 的工具。**網站本身不會用到這裡的東西**，只有當你要重新產生 `assets/` 裡的圖片時才需要跑。

- `extract2.py`：底層的影像處理函式（背景估算、去背、連通區塊分析）
- `extract_all.py`：主程式，裡面記錄了每一張圖在素材總表上的座標位置

## 怎麼跑

需要 Python 3，以及 `numpy`、`Pillow` 這兩個套件。

```bash
python3 tools/extract_all.py
```

跑完會把結果輸出到腳本裡 `OUT` 變數指定的資料夾，確認沒問題後再手動複製進 `assets/`。

原始素材總表圖路徑寫在 `extract2.py` 的 `SRC` 變數（目前指向 `Ai-chief/docs/superpowers/工程師生存實驗室素材.png`），如果檔案搬家了要同步改這一行。

## 它是怎麼去背的

素材總表的背景不是單一顏色，是一片彩色模糊漸層，所以沒辦法用一般「挑一個顏色把它變透明」的做法。這支腳本的做法是：

1. **先猜出背景長什麼樣**：只看每一格的最外圈邊框（那裡一定是背景），然後用擴散演算法把顏色往中間推，推出一張「如果沒有角色擋住，這格背景應該長這樣」的參考圖。因為背景是平滑漸層，這樣猜得很準。
2. **比對差異**：把原圖跟猜出來的背景相減，差很多的就是角色，差很少的就是背景。
3. **從外往內填**：從圖片邊緣往中間「漫延」，遇到「確定是角色」的像素就停下來。沒被漫延到的區域就是角色（這樣角色身體內部的洞也會自動算進去）。
4. **清掉鄰居**：素材總表上每一格都緊鄰著別的角色，裁切時難免會切到旁邊的圖。腳本會把「中心點不在這一格範圍內」或「延伸出裁切框外」的碎塊丟掉，只留下屬於這一格的部分。

## 為什麼每一格的座標是手動寫死的

素材總表的排列不是規則的方格，每個角色的大小、延伸範圍都不一樣（例如有的角色筆電會超出格線、有的旁邊有對話框或箭頭），所以座標是一格一格對著原圖量出來的，寫在 `extract_all.py` 的 `ITEMS` 清單裡。

`MARGIN` 控制每一格往外多抓多少範圍（抓多一點才不會切到角色，但抓太多會吃到隔壁）；`OVERRIDE` 是少數幾格的特例，因為它們上下左右能抓的空間不一樣。

跑完之後主程式會印出一張表，`NOTES` 欄位如果出現 `STILL-CLIPPED`，代表那一格的角色被裁切框切到了，要回去把 `ITEMS` 裡對應的座標調大一點再跑一次。
